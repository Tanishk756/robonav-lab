ROBONAV LAB v1.5 - TANISHK SINGHAL

Extract the full repository and open index.html. Keep all eight runtime files:
index.html, style.css, navigation.js, core.js, showcase.js, sharing.js, app.js, navigation-worker.js.
No backend, install, internet or API keys are needed to use it.

Verify v1.5, five planners, eight environments and three controllers.
For the new demo, expand Robot configuration:
- Controller: Dynamic window (DWA)
- Navigation map: LiDAR observed map
- Unknown cells: Explore: assume free
- Optional: enable Moving grid carts
Toggle Observed map / unknown cells, then Run mission.

The robot discovers walls through scans and replans. The mission panel explains
stops and shows observed fraction, clearance, replans and recovery attempts.
Conservative unknown mode may reject distant goals before exploration.

Compare planners/controllers and export JSON to save a reusable experiment.
Map export saves the initial scene/settings, not a paused mission snapshot.
Carts are deterministic grid obstacles that yield to the robot, not pedestrians.
Ground-truth pose is used; this release maps occupancy but does not localize.

If file workers are restricted, comparisons use a synchronous fallback.
For background comparisons, serve with python -m http.server 8000 if Python
is installed, then open http://localhost:8000. Offline file opening still works.

See README.md, docs/VALIDATION.md and docs/IMPLEMENTATION-PLAN.md.

PUBLIC USE AND SHARING
Open https://tanishk756.github.io/robonav-lab/ or use the offline release ZIP.
Choose one of six gallery examples and press Load example.
Press Share experiment link to include edited maps and initial settings.
Copy the generated URL; anyone with it can read and run that experiment.
Links do not capture ongoing mission progress. Export JSON is a backup.
Export experiment report saves versioned settings and measured results.

See CONTRIBUTING.md to help, SECURITY.md for private vulnerability reports,
and RELEASE-CHECKLIST.md for publishing a tested package.

INTERACTIVE EXPERIENCE
Start guided demo at the top of the page; it runs, inserts an obstacle, compares
routes and pauses automatically. Simple view reduces controls on small screens.
Choose a challenge category, configure before starting, then complete a fresh run.
Scrub Mission replay or click event markers; the live robot stays unchanged.
Compare planners for route overlays and controllers for synchronized playback.
Export result card PNG or readable HTML report, then share your experiment link.
Usage counters are off by default, local-only and clear when opted out.
See docs/USER-TESTING.md for the human/mobile testing checklist.
