# Suggested starter tasks

| Task | Acceptance criteria |
| --- | --- |
| Improve map legend | Explain unknown/free/occupied, hard clearance and soft cost without relying solely on color; verify mobile and keyboard access. |
| Add a failure example | Deterministic gallery entry with expected stop reason, a useful corrective action and a regression. |
| Improve CSV documentation | Document every exported column, units, empty values and the difference between geometric length and weighted cost. |
| Add a second-browser check | Run the existing browser contract in another browser and document actual coverage; do not claim universal certification. |
| Add export/import browser coverage | Validate downloaded JSON and file-picker import using an actual browser, including malformed files. |
| Improve experiment reports | Add readable HTML output with version/settings and clear timing caveats, keeping JSON machine-readable. |

Larger work such as pose estimation, resolution changes and independently moving obstacles should start with a design issue. See IMPLEMENTATION-PLAN.md.
