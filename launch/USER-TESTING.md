# First-time and physical-device launch checks

Status: automated Edge, Chrome and Firefox checks are available. Mobile screenshots are emulated. No first-time human sessions or physical-phone sessions have been completed by this agent.

## Five short participant sessions

Recruit a small, varied set of volunteers yourself: someone learning robotics, a software engineer and people unfamiliar with the interface. Ask permission to observe and take notes. Give tasks without explaining where to click:

1. Tell me what the tool does after looking at the first screen.
2. Start a demonstration and explain why the route changed.
3. Choose a challenge and explain its objective.
4. Scrub a replay and return to the live state.
5. Share an experiment and reopen it in another tab.
6. Export a result card and tell me what its measurements mean.

Record task completion, confusion, time-to-first-demo and exact wording that misled them. Do not invent participant quotes or completion rates. Fix repeated friction before broad promotion.

## Physical mobile check

On an actual Android Chrome device and iPhone Safari if available: test touch targets, scrolling, portrait/landscape, simple view, canvas editing, guided demo, challenge controls, replay scrubber, link copy/paste, PNG/HTML downloads and share reload. Note device/browser versions. Keep OS accessibility font sizing and keyboard navigation in scope.

## Results template

Date / participant or anonymous session ID / device and browser / task / completed without help? / observed confusion / change proposed / retest outcome.

This checklist remains a human follow-up, not an automated pass certificate.
