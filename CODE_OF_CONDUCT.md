# Community conduct

Be respectful and constructive. Discuss technical choices with evidence and assume good intent. Help newcomers understand the code and distinguish measured behavior from unsupported claims.

Harassment, discrimination, threats, personal attacks, doxxing and spam are not acceptable. Do not publish another person's private information. Respect maintainers' and contributors' time; a proposal is not a promise of implementation.

Maintainers may edit or remove harmful content, close disruptive discussions, or restrict participation. Reports should go to the maintainer through a private contact channel listed on their GitHub profile. For software vulnerabilities, follow SECURITY.md rather than opening a public issue with exploit details.

This policy applies to project issues, pull requests and other official project spaces.
