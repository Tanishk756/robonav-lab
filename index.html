Your first mission

  1. Pick an environment and a planner.
  2. Click Run mission to follow the planned route. Pause or reset at any time.
  3. Click Block route ahead while running to see obstacle-triggered replanning.
  4. Use the editor to draw walls, erase cells, or move start and goal.
  5. Click Compare planners, then export results for your portfolio.

Keyboard controls

Space: run/pause · R: reset · 1–4: edit tools. Focus the map, use arrow keys to select a cell, then Enter to apply the tool.

What this model assumes

Ground-truth position and a fully known map. Obstacles you insert update the map immediately. LiDAR is visualised independently; it does not build the map. Choose heading-based waypoint control or pure pursuit with a forward collision check and waypoint fallback. Footprint inflation excludes unsafe robot-centre cells; transition checks validate graph edges.

Exported telemetry uses simulation time. Controller comparisons use the same fixed physics timestep. See README.md for equations, limitations and a demo script.
