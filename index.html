Robot configuration

LiDAR mapping updates at 5 Hz. Unknown space is dark. Grid carts move one cell per second and yield to the robot. DWA samples acceleration-limited velocity commands; emergency stops override limits.

Purple cells penalize proximity outside the hard safety envelope. Higher weight favors wider routes; zero weight or band restores distance-only planning.

Amber halos show obstacle inflation; shaded cells exclude robot centres. The teal ring shows robot radius plus safety margin. Configuration changes reset the mission.

Your first mission

  1. Pick an environment and a planner.
  2. Click Run mission to follow the planned route. Pause or reset at any time.
  3. Click Block route ahead while running to see obstacle-triggered replanning.
  4. Use the editor to draw walls, erase cells, or move start and goal.
  5. Click Compare planners, then export results for your portfolio.

Keyboard controls

Space: run/pause · R: reset · 1–4: edit tools. Focus the map, use arrow keys to select a cell, then Enter to apply the tool.

What this model assumes

Ground-truth position. Fully known mode plans from world occupancy; sensor mode builds a log-odds map using ideal LiDAR at 5 Hz. Optimistic mode explores unknown cells; conservative mode blocks them. Inserted walls enter sensor planning only after observation. Choose any of five planners across eight environments. Purple cells show soft proximity costs; amber halos and the teal ring show hard clearance. Choose heading-based waypoint control or pure pursuit with a forward collision check and waypoint fallback. Footprint inflation excludes unsafe robot-centre cells; exact transition checks validate graph edges. Dynamic window samples acceleration-limited commands. Moving grid carts are deterministic and yield to the robot.

Exported telemetry uses simulation time. Controller comparisons use the same fixed physics timestep. See README.md for equations, limitations and a demo script.
